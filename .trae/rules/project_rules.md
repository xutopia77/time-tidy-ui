# Time Capsule 图片视频文件管理系统 - 项目规则说明

## 一、项目概述

Time Capsule 是一个基于 Vue 3 和 TypeScript 开发的图片视频文件管理前端界面，旨在提供高效、便捷的多媒体文件管理体验。系统通过与后端 API 交互，实现对本地或远程存储的图片和视频文件进行分类、检索、标注和操作。

## 二、技术架构

### 核心技术栈
- **前端框架**: Vue 3 + TypeScript
- **状态管理**: Pinia
- **路由管理**: Vue Router
- **HTTP 客户端**: Axios
- **图标库**: IconPark
- **构建工具**: Vite
- **代码规范**: ESLint + Prettier

### 项目结构
```
src/
├── assets/           # 静态资源
├── components/       # UI 组件
│   ├── AdminEntry/   # 管理员入口组件
│   ├── HomeEntry/    # 主界面组件
│   │   ├── FileExplorer/  # 文件浏览器组件
│   │   └── WorkPanel/     # 工作面板组件
│   └── AppEntry.vue      # 应用主入口组件
├── stores/           # Pinia 状态管理
├── utils/            # 工具函数
│   ├── dataTypedef.ts    # 数据类型定义
│   └── utils.ts          # 实用工具函数
├── router/           # 路由配置
└── main.ts           # 应用入口
```

## 三、核心功能模块

### 1. 文件浏览模块
- **FileExplorer**: 主文件浏览区域，展示图片和文件夹卡片
- **ImageCard**: 图片文件展示卡片，显示缩略图、文件名、大小、时间、标签等等
- **FolderCard**: 文件夹展示卡片
- **FileNavHeader**: 文件导航头部，显示当前位置和路径

### 2. 工作面板模块
- **WorkInfo**: 文件基础信息展示
- **WorkTag**: 文件标签管理
- **WorkOperate**: 文件操作功能
- **WorkTree**: 目录树结构展示

### 3. 文件操作模块
- **FileTransfer**: 文件移动/复制操作界面
- **SearchSet**: 搜索和排序设置界面
- **PageSet**: 页面设置界面

### 4. 管理员功能模块
- **TagsMng**: 标签管理界面
- **PrjSet**: 项目设置界面
- **DbInfo**: 数据库信息界面

## 四、数据模型

### 核心数据类型 (`dataTypedef.ts`)
- **File**: 文件实体，包含ID、名称、路径、大小、时间、类型、标签等属性
- **DirItem**: 目录实体，包含ID、名称、路径、统计信息等
- **TagItem**: 标签实体，包含ID、名称、颜色等
- **Repo**: 仓库实体，用于管理多个文件路径


## 五、状态管理

使用 Pinia 进行全局状态管理，`AppStore` 主要包含以下主要状态：
- **项目信息**: 项目路径、仓库路径等
- **文件列表**: 当前目录的文件和文件夹列表
- **选中文件**: 当前选中的文件信息
- **标签信息**: 所有标签列表
- **UI状态**: 卡片尺寸、页面显示控制等
- **日志信息**: 系统操作日志

## 六、业务流程

### 1. 项目初始化流程
1. 应用启动时，`AppEntry.vue` 初始化环境模式和平台类型
2. 设置服务器前缀
3. 调用 `Utils.init()` 进行系统初始化
4. 获取项目信息和文件列表
5. 启动心跳检测机制

### 2. 文件浏览流程
1. 用户进入主页，显示 `FileExplorer` 组件
2. 根据当前路径获取文件和文件夹列表
3. 使用 `convert_to_file_item` 函数将后端数据转换为前端模型
4. 文件按类型分类为图片、视频等不同类型卡片
5. 支持 Shift 键批量选择功能


## 七、UI 设计规范

### 1. 主题样式
- 使用 CSS 变量定义主题色，支持深色模式
- 统一样式类名规范（如 `.xc-button`, `.xc-card` 等）

### 2. 响应式布局
- 主界面采用左右分栏布局，左侧文件浏览器，右侧工作面板
- 工作面板宽度可调节（20%-固定像素）
- 卡片尺寸支持动态调整

### 3. 交互设计
- 支持键盘快捷键操作
- 提供丰富的消息通知机制
- 操作确认对话框防止误操作

## 八、API 交互规范

### 1. HTTP 请求
- 使用 Axios 进行 HTTP 请求
- 统一的请求/响应数据结构
- 错误处理和用户反馈机制

### 2. 数据转换
- 路径统一转换为 Linux 格式（使用 `/` 分隔符）

### 3. 实时性保障
- 定时心跳检测确保连接正常
- 文件操作后自动刷新相关数据

## 九、扩展性和维护性

### 1. 模块化设计
- 组件职责单一，便于独立开发和测试
- 工具函数集中管理，提高复用性
- 类型定义统一，增强代码可维护性

### 2. 配置化管理
- 项目设置通过 `PrjSetReq/Resp` 结构化管理
- 支持多种处理策略（全量/增量）

### 3. 可定制性
- 标签系统支持自定义颜色和名称
- 文件展示方式可配置（排序、过滤等）

该项目提供了一个功能完备、易于扩展的图片视频文件管理解决方案，具有良好的用户体验和系统可维护性。
